# Phase 1: Platform and Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in student can create a project, write in an editor that autosaves every change as a numbered revision, restore any revision, import a v1 Appuscholar backup, and do all of this on a private Vercel preview URL.

**Architecture:** pnpm monorepo. `apps/web` (Next.js) owns sign-in and the UI and mints short-lived API tokens. `apps/api` (Hono on Node) owns all data access behind a `Store` interface with an in-memory implementation for tests and a Drizzle/Neon implementation for production. `packages/core` holds pure logic (HTML sanitising, v1 backup parsing) shared by both apps. Every document write is an append-only revision.

**Tech Stack:** Node 22, pnpm 10, Turborepo 2, TypeScript 5.9, Next.js 16, React 19, next-auth 5.0.0-beta.32 with @auth/drizzle-adapter, Hono 4, Drizzle ORM 0.45 + drizzle-kit 0.31, @neondatabase/serverless 1.2, jose 6, isomorphic-dompurify 4, TipTap 3, Zod 4, Vitest 5, Playwright 1.64, Vercel (two projects), Neon Postgres via Vercel Marketplace, Resend for magic-link email.

**Spec:** `docs/superpowers/specs/2026-10-13-appuscholar-v2-design.md` (sections 3, 4, 5 auth only, 9, 10, 11 phase 1).

## Global Constraints

- Node `>=22 <23`, pnpm `>=10`. `packageManager` field pinned in root `package.json`.
- TypeScript `strict: true`, `noUncheckedIndexedAccess: true` everywhere.
- `packages/core` imports nothing from `react`, `next`, `hono`, `node:*`, or `drizzle-orm`. Enforced by an ESLint `no-restricted-imports` rule in that package.
- Documents are stored as HTML strings. Every HTML string that reaches the database passes through `sanitizeHtml()` from `packages/core` first. No exceptions.
- Revisions are append-only. No `UPDATE` or `DELETE` on `document_revisions`.
- Content-Security-Policy on every web response: `default-src 'self'; script-src 'self' 'nonce-<n>' 'strict-dynamic'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' blob: data: https://*.public.blob.vercel-storage.com; connect-src 'self' <API_URL>; frame-ancestors 'none'; base-uri 'self'; form-action 'self'`.
- Secrets live only in `.env.local` (git-ignored) and Vercel env vars. `.env.example` lists every variable with a placeholder.
- All commits: Conventional Commits prefix (`feat:`, `fix:`, `test:`, `chore:`) and the trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- The repo is private. Copyright notice in `LICENSE.md`: original design and text © 2026 Dr. Shiv Raj Sharma; v2 code © 2026 OJ (Ojaswa Sharma); all rights reserved pending agreement.

## Review Focus

1. A v1 backup whose `appu_docs` contains `<img onerror=…>` or `<svg onload=…>` must import with those attributes stripped and the rest of the document intact. Test in Task 3.
2. Two autosaves with identical body must produce one revision, not two. Test in Task 4.
3. A document PUT with a body over 2 MB must be rejected with 413 and the previous revision untouched. Test in Task 4.
4. A request with an expired API token must get 401, never a 500 or an empty 200. Test in Task 4.
5. Restoring revision 3 of a document that is at revision 7 must create revision 8 with the body of 3, not rewind the counter. Test in Task 4.

```ts
import DOMPurify from "isomorphic-dompurify";

const ALLOWED_TAGS = ["p","div","br","b","i","u","s","strong","em","ul","ol","li","h1","h2","h3","h4","h5","h6","blockquote","span","img","table","thead","tbody","tr","td","th","a","sup","sub","hr","pre","code","figure","figcaption","mark"];
const ALLOWED_ATTR = ["href","src","alt","title","colspan","rowspan","class","data-origin","style"];
const ALLOWED_URI = /^(?:https?:|mailto:|data:image\/(?:png|jpe?g|gif|webp);base64,)/i;

export function sanitizeHtml(html: string): string {
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS,
    ALLOWED_ATTR,
    ALLOWED_URI_REGEXP: ALLOWED_URI,
    FORBID_TAGS: ["script","style","svg","math","iframe","object","embed","form","input"],
    KEEP_CONTENT: true
  });
}

export function wordCount(html: string): number {
  const text = html.replace(/<[^>]+>/g, " ").replace(/&nbsp;/g, " ").trim();
  return text ? text.split(/\s+/).length : 0;
}
```

Note: `KEEP_CONTENT: true` keeps the text inside a forbidden `<svg>` but drops the tag and attributes, which is what the first test expects.

```ts
import { z } from "zod";
import { sanitizeHtml } from "./sanitize";

export type V1Document = { id: string; title: string; bodyHtml: string; updated: number };
export type V1Project = { id: string; title: string; stage?: string };
export type V1Backup = { exported: string; documents: V1Document[]; projects: V1Project[] };
export type V1ParseResult = { ok: true; backup: V1Backup } | { ok: false; reason: "not-json" | "not-appuscholar" | "no-documents" };

const Bundle = z.object({
  app: z.literal("appuscholar"),
  v: z.number(),
  exported: z.string().optional(),
  data: z.record(z.string(), z.string())
});
const RawDoc = z.object({ id: z.string(), title: z.string().default("Untitled"), body: z.string().default(""), updated: z.number().default(0) });
const RawProject = z.object({ id: z.string(), title: z.string().default("Untitled project"), stage: z.string().optional() });

const LOOKS_LIKE_HTML = /<(p|div|br|b|i|u|strong|em|ul|ol|li|h[1-6]|blockquote|span|img|table|thead|tbody|tr|td|th|svg|a|sup|sub|hr|pre|code|font|figure)[\s>\/]/i;

function escapeText(s: string): string {
  return s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
}

export function v1BodyToHtml(body: string): string {
  const html = LOOKS_LIKE_HTML.test(body) ? body : "<p>" + escapeText(body).replace(/\n/g, "<br>") + "</p>";
  return sanitizeHtml(html);
}

function parseJsonArray<T>(text: string | undefined, schema: z.ZodType<T>): T[] {
  if (!text) return [];
  try {
    const arr = JSON.parse(text);
    if (!Array.isArray(arr)) return [];
    return arr.flatMap((x) => { const r = schema.safeParse(x); return r.success ? [r.data] : []; });
  } catch { return []; }
}

export function parseV1Backup(text: string): V1ParseResult {
  let json: unknown;
  try { json = JSON.parse(text); } catch { return { ok: false, reason: "not-json" }; }
  const bundle = Bundle.safeParse(json);
  if (!bundle.success) return { ok: false, reason: "not-appuscholar" };
  const rawDocs = parseJsonArray(bundle.data.data["appu_docs"], RawDoc);
  if (rawDocs.length === 0) return { ok: false, reason: "no-documents" };
  const documents: V1Document[] = rawDocs.map((d) => ({ id: d.id, title: d.title.trim() || "Untitled", bodyHtml: v1BodyToHtml(d.body), updated: d.updated }));
  const projects: V1Project[] = parseJsonArray(bundle.data.data["appu_projects"], RawProject).map((p) => ({ id: p.id, title: p.title, ...(p.stage ? { stage: p.stage } : {}) }));
  return { ok: true, backup: { exported: bundle.data.exported ?? "", documents, projects } };
}
```

```ts
import type { Store, Project, DocumentSummary, DocumentWithBody, DocumentRevision, RevisionSummary, NewRevision } from "./types";

type DocRow = { id: string; projectId: string; title: string; kind: string; createdAt: Date; updatedAt: Date };

export class MemoryStore implements Store {
  private projects = new Map<string, Project>();
  private docs = new Map<string, DocRow>();
  private revs = new Map<string, DocumentRevision[]>();

  private ownsProject(userId: string, projectId: string): boolean {
    return this.projects.get(projectId)?.userId === userId;
  }
  private ownedDoc(userId: string, docId: string): DocRow | null {
    const d = this.docs.get(docId);
    return d && this.ownsProject(userId, d.projectId) ? d : null;
  }
  private latest(docId: string): DocumentRevision {
    const list = this.revs.get(docId) ?? [];
    const last = list[list.length - 1];
    if (!last) throw new Error("document without revisions: " + docId);
    return last;
  }
  private summary(d: DocRow): DocumentSummary {
    const r = this.latest(d.id);
    return { id: d.id, projectId: d.projectId, title: d.title, kind: d.kind, currentSeq: r.seq, wordCount: r.wordCount, updatedAt: d.updatedAt };
  }

  async createProject(userId: string, title: string): Promise<Project> {
    const p: Project = { id: crypto.randomUUID(), userId, title, field: "psychology", stage: "idea", contentLang: "en", createdAt: new Date() };
    this.projects.set(p.id, p);
    return p;
  }
  async listProjects(userId: string): Promise<Project[]> {
    return [...this.projects.values()].filter(p => p.userId === userId).sort((a, b) => b.createdAt.getTime() - a.createdAt.getTime());
  }
  async getProject(userId: string, id: string): Promise<Project | null> {
    const p = this.projects.get(id);
    return p && p.userId === userId ? p : null;
  }

  async createDocument(userId: string, projectId: string, title: string, kind: string, first: NewRevision): Promise<DocumentWithBody | null> {
    if (!this.ownsProject(userId, projectId)) return null;
    const now = new Date();
    const d: DocRow = { id: crypto.randomUUID(), projectId, title, kind, createdAt: now, updatedAt: now };
    this.docs.set(d.id, d);
    const r: DocumentRevision = { id: crypto.randomUUID(), documentId: d.id, seq: 1, ...first, createdAt: now };
    this.revs.set(d.id, [r]);
    return { ...this.summary(d), bodyHtml: r.bodyHtml };
  }
  async listDocuments(userId: string, projectId: string): Promise<DocumentSummary[] | null> {
    if (!this.ownsProject(userId, projectId)) return null;
    return [...this.docs.values()].filter(d => d.projectId === projectId).map(d => this.summary(d)).sort((a, b) => b.updatedAt.getTime() - a.updatedAt.getTime());
  }
  async getDocument(userId: string, id: string): Promise<DocumentWithBody | null> {
    const d = this.ownedDoc(userId, id);
    return d ? { ...this.summary(d), bodyHtml: this.latest(d.id).bodyHtml } : null;
  }
  async renameDocument(userId: string, id: string, title: string): Promise<DocumentSummary | null> {
    const d = this.ownedDoc(userId, id);
    if (!d) return null;
    d.title = title; d.updatedAt = new Date();
    return this.summary(d);
  }

  async appendRevision(userId: string, documentId: string, rev: NewRevision): Promise<DocumentRevision | null> {
    const d = this.ownedDoc(userId, documentId);
    if (!d) return null;
    const list = this.revs.get(documentId)!;
    const r: DocumentRevision = { id: crypto.randomUUID(), documentId, seq: list.length + 1, ...rev, createdAt: new Date() };
    list.push(r);
    d.updatedAt = r.createdAt;
    return r;
  }
  async listRevisions(userId: string, documentId: string): Promise<RevisionSummary[] | null> {
    if (!this.ownedDoc(userId, documentId)) return null;
    return [...(this.revs.get(documentId) ?? [])].reverse().map(({ bodyHtml: _b, ...rest }) => rest);
  }
  async getRevision(userId: string, documentId: string, seq: number): Promise<DocumentRevision | null> {
    if (!this.ownedDoc(userId, documentId)) return null;
    return (this.revs.get(documentId) ?? []).find(r => r.seq === seq) ?? null;
  }
}
```

```ts
export type AuthEnv = { Variables: { userId: string; email: string } };

export function apiAuth(secret: string) {
  const key = new TextEncoder().encode(secret);
  return createMiddleware<AuthEnv>(async (c, next) => {
    const h = c.req.header("authorization") ?? "";
    const tok = h.startsWith("Bearer ") ? h.slice(7) : "";
    if (!tok) return c.json({ error: "unauthorized" }, 401);
    try {
      const { payload } = await jwtVerify(tok, key, { algorithms: ["HS256"] });
      if (!payload.sub) return c.json({ error: "unauthorized" }, 401);
      c.set("userId", payload.sub);
      c.set("email", typeof payload.email === "string" ? payload.email : "");
      await next();
    } catch {
      return c.json({ error: "unauthorized" }, 401);
    }
  });
}
```

```ts
import { Hono } from "hono";
import { z } from "zod";
import { sanitizeHtml, wordCount } from "@appuscholar/core";
import type { Store } from "../store/types";
import type { AuthEnv } from "../auth";

const Put = z.object({ bodyHtml: z.string(), title: z.string().trim().min(1).max(200).optional() });

export function documentRoutes(store: Store, maxBodyBytes: number) {
  const r = new Hono<AuthEnv>();

  r.get("/:id", async (c) => {
    const d = await store.getDocument(c.get("userId"), c.req.param("id"));
    return d ? c.json(d) : c.json({ error: "not-found" }, 404);
  });

  r.put("/:id", async (c) => {
    const raw = await c.req.text();
    if (raw.length > maxBodyBytes) return c.json({ error: "too-large" }, 413);
    let parsed: unknown; try { parsed = JSON.parse(raw); } catch { return c.json({ error: "invalid" }, 400); }
    const body = Put.safeParse(parsed);
    if (!body.success) return c.json({ error: "invalid" }, 400);
    const userId = c.get("userId");
    const current = await store.getDocument(userId, c.req.param("id"));
    if (!current) return c.json({ error: "not-found" }, 404);
    if (body.data.title && body.data.title !== current.title) await store.renameDocument(userId, current.id, body.data.title);
    const clean = sanitizeHtml(body.data.bodyHtml);
    if (clean === current.bodyHtml) {
      const rev = await store.getRevision(userId, current.id, current.currentSeq);
      return c.json({ document: await store.getDocument(userId, current.id), revision: rev, created: false });
    }
    const rev = await store.appendRevision(userId, current.id, { bodyHtml: clean, authorKind: "web", authorLabel: c.get("email"), wordCount: wordCount(clean) });
    return c.json({ document: await store.getDocument(userId, current.id), revision: rev, created: true });
  });

  r.get("/:id/revisions", async (c) => {
    const list = await store.listRevisions(c.get("userId"), c.req.param("id"));
    return list ? c.json(list) : c.json({ error: "not-found" }, 404);
  });

  r.get("/:id/revisions/:seq", async (c) => {
    const seq = Number(c.req.param("seq"));
    if (!Number.isInteger(seq) || seq < 1) return c.json({ error: "invalid" }, 400);
    const rev = await store.getRevision(c.get("userId"), c.req.param("id"), seq);
    return rev ? c.json(rev) : c.json({ error: "not-found" }, 404);
  });

  r.post("/:id/restore/:seq", async (c) => {
    const seq = Number(c.req.param("seq"));
    if (!Number.isInteger(seq) || seq < 1) return c.json({ error: "invalid" }, 400);
    const userId = c.get("userId");
    const old = await store.getRevision(userId, c.req.param("id"), seq);
    if (!old) return c.json({ error: "not-found" }, 404);
    const rev = await store.appendRevision(userId, old.documentId, { bodyHtml: old.bodyHtml, authorKind: "restore", authorLabel: `restored revision ${seq}`, wordCount: old.wordCount });
    return c.json({ document: await store.getDocument(userId, old.documentId), revision: rev });
  });

  return r;
}
```

`apps/api/src/store/drizzle.ts`:
```ts
import { and, desc, eq, sql } from "drizzle-orm";
import { projects, documents, documentRevisions, type Db } from "@appuscholar/db";
import type { Store, Project, DocumentSummary, DocumentWithBody, DocumentRevision, RevisionSummary, NewRevision, AuthorKind } from "./types";

export class DrizzleStore implements Store {
  constructor(private d: Db) {}

  private async ownedDoc(userId: string, docId: string) {
    const rows = await this.d.select({ doc: documents, project: projects }).from(documents).innerJoin(projects, eq(projects.id, documents.projectId)).where(and(eq(documents.id, docId), eq(projects.userId, userId))).limit(1);
    return rows[0]?.doc ?? null;
  }
  private async latest(docId: string) {
    const rows = await this.d.select().from(documentRevisions).where(eq(documentRevisions.documentId, docId)).orderBy(desc(documentRevisions.seq)).limit(1);
    const r = rows[0];
    if (!r) throw new Error("document without revisions: " + docId);
    return this.toRev(r);
  }
  private toRev(r: typeof documentRevisions.$inferSelect): DocumentRevision {
    return { id: r.id, documentId: r.documentId, seq: r.seq, bodyHtml: r.bodyHtml, authorKind: r.authorKind as AuthorKind, authorLabel: r.authorLabel, wordCount: r.wordCount, createdAt: r.createdAt };
  }
  private async summary(doc: typeof documents.$inferSelect): Promise<DocumentSummary> {
    const r = await this.latest(doc.id);
    return { id: doc.id, projectId: doc.projectId, title: doc.title, kind: doc.kind, currentSeq: r.seq, wordCount: r.wordCount, updatedAt: doc.updatedAt };
  }

  async createProject(userId: string, title: string): Promise<Project> {
    const [p] = await this.d.insert(projects).values({ userId, title }).returning();
    return p!;
  }
  async listProjects(userId: string): Promise<Project[]> {
    return this.d.select().from(projects).where(eq(projects.userId, userId)).orderBy(desc(projects.createdAt));
  }
  async getProject(userId: string, id: string): Promise<Project | null> {
    const rows = await this.d.select().from(projects).where(and(eq(projects.id, id), eq(projects.userId, userId))).limit(1);
    return rows[0] ?? null;
  }

  async createDocument(userId: string, projectId: string, title: string, kind: string, first: NewRevision): Promise<DocumentWithBody | null> {
    if (!(await this.getProject(userId, projectId))) return null;
    const [doc] = await this.d.insert(documents).values({ projectId, title, kind }).returning();
    const [rev] = await this.d.insert(documentRevisions).values({ documentId: doc!.id, seq: 1, ...first }).returning();
    await this.d.update(documents).set({ currentRevisionId: rev!.id }).where(eq(documents.id, doc!.id));
    return { ...(await this.summary(doc!)), bodyHtml: rev!.bodyHtml };
  }
  async listDocuments(userId: string, projectId: string): Promise<DocumentSummary[] | null> {
    if (!(await this.getProject(userId, projectId))) return null;
    const rows = await this.d.select().from(documents).where(eq(documents.projectId, projectId)).orderBy(desc(documents.updatedAt));
    return Promise.all(rows.map(r => this.summary(r)));
  }
  async getDocument(userId: string, id: string): Promise<DocumentWithBody | null> {
    const doc = await this.ownedDoc(userId, id);
    if (!doc) return null;
    const r = await this.latest(doc.id);
    return { ...(await this.summary(doc)), bodyHtml: r.bodyHtml };
  }
  async renameDocument(userId: string, id: string, title: string): Promise<DocumentSummary | null> {
    const doc = await this.ownedDoc(userId, id);
    if (!doc) return null;
    const [updated] = await this.d.update(documents).set({ title, updatedAt: new Date() }).where(eq(documents.id, id)).returning();
    return this.summary(updated!);
  }

  async appendRevision(userId: string, documentId: string, rev: NewRevision): Promise<DocumentRevision | null> {
    const doc = await this.ownedDoc(userId, documentId);
    if (!doc) return null;
    const [row] = await this.d.insert(documentRevisions).values({
      documentId, ...rev,
      seq: sql`(select coalesce(max(${documentRevisions.seq}), 0) + 1 from ${documentRevisions} where ${documentRevisions.documentId} = ${documentId})`
    }).returning();
    await this.d.update(documents).set({ currentRevisionId: row!.id, updatedAt: row!.createdAt }).where(eq(documents.id, documentId));
    return this.toRev(row!);
  }
  async listRevisions(userId: string, documentId: string): Promise<RevisionSummary[] | null> {
    if (!(await this.ownedDoc(userId, documentId))) return null;
    const rows = await this.d.select({ id: documentRevisions.id, documentId: documentRevisions.documentId, seq: documentRevisions.seq, authorKind: documentRevisions.authorKind, authorLabel: documentRevisions.authorLabel, wordCount: documentRevisions.wordCount, createdAt: documentRevisions.createdAt }).from(documentRevisions).where(eq(documentRevisions.documentId, documentId)).orderBy(desc(documentRevisions.seq));
    return rows.map(r => ({ ...r, authorKind: r.authorKind as AuthorKind }));
  }
  async getRevision(userId: string, documentId: string, seq: number): Promise<DocumentRevision | null> {
    if (!(await this.ownedDoc(userId, documentId))) return null;
    const rows = await this.d.select().from(documentRevisions).where(and(eq(documentRevisions.documentId, documentId), eq(documentRevisions.seq, seq))).limit(1);
    return rows[0] ? this.toRev(rows[0]) : null;
  }
}
```

The `seq` subquery plus the unique index on `(document_id, seq)` makes concurrent saves safe: the loser of a race gets a unique-violation error, which `onError` turns into a 500 and the editor's autosave retries.

```ts
import { NextResponse, type NextRequest } from "next/server";

export function middleware(req: NextRequest) {
  const nonce = Buffer.from(crypto.randomUUID()).toString("base64");
  const api = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:8788";
  const csp = [
    "default-src 'self'",
    `script-src 'self' 'nonce-${nonce}' 'strict-dynamic'`,
    "style-src 'self' 'unsafe-inline' https://fonts.googleapis.com",
    "font-src 'self' https://fonts.gstatic.com",
    "img-src 'self' blob: data: https://*.public.blob.vercel-storage.com",
    `connect-src 'self' ${api}`,
    "frame-ancestors 'none'",
    "base-uri 'self'",
    "form-action 'self'"
  ].join("; ");
  const headers = new Headers(req.headers);
  headers.set("x-nonce", nonce);
  const res = NextResponse.next({ request: { headers } });
  res.headers.set("Content-Security-Policy", csp);
  res.headers.set("X-Content-Type-Options", "nosniff");
  res.headers.set("Referrer-Policy", "strict-origin-when-cross-origin");
  return res;
}
```

```ts
let cached: { token: string; expiresAt: number } | null = null;
const API = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:8788";

async function getToken(): Promise<string> {
  const now = Math.floor(Date.now() / 1000);
  if (cached && cached.expiresAt - now > 60) return cached.token;
  const r = await fetch("/api/token", { cache: "no-store" });
  if (!r.ok) throw new Error("not signed in");
  cached = await r.json();
  return cached!.token;
}

export class ApiError extends Error { constructor(public status: number, public code: string) { super(`${status} ${code}`); } }

export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const token = await getToken();
  const r = await fetch(API + path, { ...init, headers: { ...(init.headers ?? {}), authorization: "Bearer " + token, ...(init.body ? { "content-type": "application/json" } : {}) } });
  if (!r.ok) {
    let code = "error"; try { code = (await r.json()).error ?? code; } catch { /* ignore */ }
    throw new ApiError(r.status, code);
  }
  return r.json() as Promise<T>;
}
```

```ts
"use client";
import { useEffect, useMemo, useState } from "react";
import { apiFetch } from "./api";

export type SaveStatus = "saved" | "saving" | "error" | "dirty";
type SaveResult = { seq: number; created: boolean };

export function createAutosaver(o: { initialHtml: string; save: (html: string) => Promise<SaveResult>; delayMs: number; onStatus?: (s: SaveStatus, seq?: number) => void }) {
  let lastSaved = o.initialHtml;
  let pending: string | null = null;
  let timer: ReturnType<typeof setTimeout> | null = null;
  let status: SaveStatus = "saved";
  const set = (s: SaveStatus, seq?: number) => { status = s; o.onStatus?.(s, seq); };

  async function flush() {
    timer = null;
    const html = pending; pending = null;
    if (html === null || html === lastSaved) { set("saved"); return; }
    set("saving");
    try {
      const r = await o.save(html);
      lastSaved = html;
      set("saved", r.seq);
    } catch {
      pending = html;
      set("error");
    }
  }
  return {
    onChange(html: string) {
      if (html === lastSaved && pending === null) { set("saved"); return; }
      pending = html;
      set("dirty");
      if (timer) clearTimeout(timer);
      timer = setTimeout(() => { void flush(); }, o.delayMs);
    },
    flushNow: flush,
    getStatus: () => status
  };
}

export function useAutosave(docId: string, initialHtml: string, initialSeq: number) {
  const [status, setStatus] = useState<SaveStatus>("saved");
  const [currentSeq, setSeq] = useState(initialSeq);
  const saver = useMemo(() => createAutosaver({
    initialHtml,
    delayMs: 1500,
    save: async (html) => {
      const r = await apiFetch<{ revision: { seq: number }; created: boolean }>(`/documents/${docId}`, { method: "PUT", body: JSON.stringify({ bodyHtml: html }) });
      return { seq: r.revision.seq, created: r.created };
    },
    onStatus: (s, seq) => { setStatus(s); if (seq) setSeq(seq); }
  }), [docId, initialHtml]);
  useEffect(() => {
    const h = (e: BeforeUnloadEvent) => { if (saver.getStatus() === "dirty" || saver.getStatus() === "saving") { e.preventDefault(); } };
    window.addEventListener("beforeunload", h);
    return () => window.removeEventListener("beforeunload", h);
  }, [saver]);
  return { status, currentSeq, onChange: saver.onChange, flushNow: saver.flushNow };
}
```

```tsx
import { parseV1Backup } from "@appuscholar/core";
import { apiFetch } from "@/lib/api";
export function ImportV1() {
  const router = useRouter();
  const [msg, setMsg] = useState<string>("");
  async function onFile(e: React.ChangeEvent<HTMLInputElement>) {
    const f = e.target.files?.[0]; if (!f) return;
    const text = await f.text();
    const parsed = parseV1Backup(text);
    if (!parsed.ok) { setMsg(parsed.reason === "not-json" ? "That file is not JSON." : parsed.reason === "not-appuscholar" ? "That file is not an Appuscholar backup." : "That backup has no documents."); return; }
    if (!confirm(`Import ${parsed.backup.documents.length} document(s) saved ${parsed.backup.exported.slice(0, 10) || "?"} into a new project?`)) return;
    setMsg("Importing…");
    const r = await apiFetch<{ projectId: string; imported: number }>("/import/v1", { method: "POST", body: JSON.stringify({ bundleText: text }) });
    setMsg(`Imported ${r.imported} document(s) ✓`);
    router.push(`/projects/${r.projectId}`);
  }
  return (
    <div className="card">
      <p>Choose the backup file you downloaded from Appuscholar v1 (it is a <code>.json</code> file). Your AI keys and access code were never in it.</p>
      <input type="file" accept="application/json,.json" onChange={onFile} data-testid="import-file" />
      <p data-testid="import-msg" style={{ color: "var(--muted)" }}>{msg}</p>
    </div>
  );
}
```
