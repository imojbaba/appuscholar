- R7 (G3): Ruling: `export type ExportDeps = ProjectExportDeps & { now: Date }`, exported from `apps/web/lib/export/projectExport.ts` (the name the plan uses, in the project export's module; the account export's `ExportDeps` in `lib/vault/export.ts` is untouched). - R9 (G4): Ruling: `text()` uses core's `docInnerText` (packages/core/src/doctext.ts:139, already v1's getEditorText for the helpers, lib/ai/actions.ts:128) on the editor's HTML — the plan's `docTextContent` does not exist — costs nothing.
- R10 (G4): Ruling: in a pop-out, `text()` and `selection()` stay synchronous by reading a mirror: the writing window posts `{type: "doc-snapshot", docId, text, selection}` on the sync channel when the editor changes (debounced) and when a pop-out says hello; the pop-out keeps the latest ("" before any).
