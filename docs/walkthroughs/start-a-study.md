# Start a study: the walk

The new first day (start-a-study spec, OJ 2026-10-27): the dashboard, Start a new study, and the guided Shape your study, which replaces the idea screen and its AI judgement. The walk in `first-run.md` is out of date: its idea screen is gone.

- **Screenshots:** taken from a local dev build, with Next.js's dev badge removed. Their files are in `screens/start-a-study/`.
- **The AI:** answered by a stand-in in the browser, using the QA fixture replies.
- **The key:** a made-up test value. No account, email or real key appears.
